# Fintter Plan - Undone

The following features from the original `fintter_plan.md` are pending, partially implemented, or require further work:

## Features
- **Advanced Gamification Engine**: No-spend day streaks, under-budget streaks, financial health score computation, milestones, and full-screen confetti burst for unlocks.
- **Rule-Based SMS/Notification Parser**: Automatic transaction detection based on incoming push notifications and SMS regex matching.
- **Recurring Transaction Engine**: Automatic triggering of recurring expenses and local push notifications for due expenses.
- **Backup & Restore**: JSON export and import capabilities for wiping and restoring the local SQLite DB.
- **App Lock**: Biometric integration for securing the app.
- **History Page Gestures**: Swipe left to delete, swipe right to duplicate. Search by note/merchant.
- **Settings Screen Expansion**: Managing default currency, default wallet, fully functional category management (reorder, edit), parser rule configuration, recurring templates, and a danger zone.
- **Quick-Add Enhancements**: Auto-scroll to suggested category, smart default selection based on history.
- **Onboarding Screens**: Welcome flow, currency setup, category setup (currently bypassing to dashboard).

## UI/UX Enhancements
- **Reduced Motion Support**: Ensure all animations respect system accessibility settings.
- **Glassmorphism Helpers**: Further integration of blur views and glassmorphic designs where specified.
