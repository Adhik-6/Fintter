# Fintter Plan - Undone

The following features from the `fintter_plan.md` are pending, partially implemented, or require further work:

## Features to Build
- **Smart SMS/Notification Parser**: Automatic transaction detection based on incoming push notifications and SMS. The parser must surface a list of "possible transactions" and let the user decide which ones are valid and edit them before adding.
- **Backup & Restore with Encryption**: The backup files must be encrypted for security.
- **App Lock & App Password**: An "App Password" mechanism specifically required for clearing data.
- **Recurring Transaction Engine**: Automatic triggering of recurring expenses and local push notifications for due expenses.
- **History Page Gestures**: Swipe left to delete, swipe right to edit. Search by note/merchant in the selected date or selected filter options.
- **Settings Screen Expansion**: Let users reorder category.
